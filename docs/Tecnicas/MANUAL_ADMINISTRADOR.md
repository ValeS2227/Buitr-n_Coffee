# Manual de administrador – Buitrón Coffee
# 1. ¿Para qué sirve el panel del administrador?
El panel del administrador sirve para llevar el control de la plataforma. Desde allí se puede:
- Llevar el registro de los usuarios.
- Consultar los pedidos.
- Gestionar los productos.
- Gestionar las reseñas de los clientes.
- Gestionar y responder los PQRS.
# 2. Inicio de sesión
El administrador inicia sesión en la misma pantalla que usan los usuarios. Al ingresar su correo electrónico y contraseña, la plataforma lo redirige automáticamente al panel de administración.
# 3. Barra lateral
Al entrar, el administrador verá una barra lateral desde la cual puede ir a cada una de las siguientes vistas.
# 3.1 Usuarios
Permite ver los usuarios registrados en el aplicativo. Desde aquí el administrador puede inhabilitar a un usuario.
# 3.2 Gestión de productos
Permite administrar el catálogo que ven los clientes. El administrador puede:
1. Crear productos.
2. Ver los productos existentes.
3. Actualizar la información de un producto.
4. Deshabilitar un producto.
# 3.3 Gestión de reseñas
Permite revisar las reseñas que dejan los usuarios y aceptarlas para que sean visibles en la plataforma.
# 3.4 Gestión de PQRS
Permite ver las peticiones, quejas, reclamos y sugerencias enviadas por los usuarios y responderlas.
# 4. Resumen (panel principal)
La plataforma cuenta con un resumen donde el administrador puede ver:
- Los productos más vendidos.
- Los productos con falta de stock (existencias bajas o agotadas).
