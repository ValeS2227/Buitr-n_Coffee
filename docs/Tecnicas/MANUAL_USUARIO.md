# Manual de usuario – Buitrón Coffee

## 1. ¿Para qué sirve Buitrón Coffee?

Buitrón Coffee es una plataforma web que cumple dos funciones:

- **Para el dueño de la empresa:** facilita la gestión de inventarios, productos, usuarios, reseñas y PQRS.
- **Para los usuarios (clientes):** ofrece una cuenta personal desde la cual pueden consultar el catálogo de productos, realizar compras y hacer seguimiento a sus pedidos.

## 2. Lo primero que ve el usuario

Antes de iniciar sesión, cualquier visitante puede ver el **nombre y el precio** de los productos. Para ver el detalle completo de cada producto, comprar y acceder a las demás funciones, es necesario **registrarse o iniciar sesión**.

## 3. Registro e inicio de sesión

### 3.1 Registro

Para crear una cuenta, el usuario debe completar los siguientes campos:

1. Nombre
2. Apellido
3. Documento de identidad
4. Dirección
5. Correo electrónico
6. Contraseña

Cuando todos los campos estén diligenciados, el usuario podrá completar el registro con éxito.

### 3.2 Inicio de sesión

Para ingresar, el usuario debe escribir el **correo electrónico** y la **contraseña** con los que se registró.

### 3.3 Cerrar sesión

Cuando termine de usar la plataforma, el usuario puede cerrar su sesión desde las opciones de su cuenta.

## 4. Catálogo de productos

Al iniciar sesión, el usuario ve el catálogo con todos los productos disponibles. Al seleccionar un producto, podrá ver:

- Nombre del producto
- Descripción
- Categoría
- Cantidad disponible (existencias)
- Precio

Allí mismo puede elegir **cuántas unidades desea agregar al carrito**.

## 5. Carrito de compras

Una vez agregados los productos, el usuario puede ir al carrito y decidir entre:

- **Continuar con la compra**, o
- **Cancelarla**.

## 6. Reseñas

En la misma página de cada producto, el usuario puede:

- **Dejar su propia reseña** sobre el producto.
- **Leer las reseñas** que han dejado otros usuarios.

## 7. Información de la empresa

El usuario también puede consultar una breve información sobre Buitrón Coffee y sus canales de comunicación.

## 8. PQRS (Peticiones, Quejas, Reclamos y Sugerencias)

La plataforma cuenta con una sección de PQRS donde el usuario puede enviar:

- Peticiones
- Quejas
- Reclamos
- Sugerencias

El administrador revisa y gestiona cada solicitud.

## 9. Perfil de usuario

Para entrar a su perfil, el usuario debe seleccionar el **ícono de la persona (muñequito)**. Desde allí puede:

- **Modificar sus datos personales**, como el nombre, el número de teléfono, entre otros.
- **Consultar el historial de sus pedidos.**
- **Ver los PQRS** que ha enviado.
